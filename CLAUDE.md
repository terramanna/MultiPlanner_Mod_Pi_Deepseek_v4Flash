# Claude project instructions

Read `AGENTS.md`, `CONTEXT.md`, `.agents/CLAUDE.md`, and the repo-local skill
tree in `.agents/skills/` before changing this repository.

Commit using the Git identity configured for your Claude entry in
`config/commit-actors.json` and include the matching trailer:

```text
Actor: <configured Claude actor>
```

See `docs/COMMIT_AUDIT.md` for the complete policy.
